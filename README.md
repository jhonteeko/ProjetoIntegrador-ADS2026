# Projeto Integrador — Seleção e Recrutamento (RH)

## Estrutura

- `frontend/` — React + TypeScript (Vite) + shadcn/ui
- `backend/` — Java + Spring Boot (Maven)
- `database/` — scripts SQL para MySQL

## Como rodar

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Database
MySQL — configuração de conexão e scripts serão adicionados em `database/`.
