# Atores

| Ator | Descrição |
| ----- | ----- |
| Candidato | Usuário externo que busca oportunidades, cadastra currículo, candidata-se a vagas e acompanha o andamento do processo. |
| Profissional de RH | Usuário interno responsável por cadastrar vagas, acompanhar candidaturas, atualizar status, solicitar documentos e revisar a triagem. |
| Administrador do sistema | Usuário responsável por cadastrar perfis internos, ajustar permissões, manter parâmetros gerais e apoiar a manutenção do sistema. |
| Sistema de IA | Serviço externo ou módulo interno que analisa currículos e requisitos da vaga para gerar uma classificação inicial de aderência. |
| Serviço de notificação | Serviço usado para enviar e-mails ou avisos aos candidatos quando houver alteração relevante no processo seletivo. |
