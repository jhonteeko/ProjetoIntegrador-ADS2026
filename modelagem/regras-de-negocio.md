# Regras de Negócio

| Código | Regra |
| ----- | ----- |
| RN01 | Um candidato não pode se candidatar mais de uma vez à mesma vaga. |
| RN02 | Somente usuários do RH podem cadastrar, editar, encerrar vagas e atualizar status de candidatos. |
| RN03 | O candidato só poderá enviar documentos de contratação quando estiver em status aprovado ou equivalente. |
| RN04 | A triagem por IA não deve aprovar ou reprovar automaticamente candidatos; ela apenas gera sugestão para análise humana. |
| RN05 | Vagas encerradas não devem aceitar novas candidaturas, mas devem manter histórico para consulta interna. |
| RN06 | O candidato deve conseguir visualizar apenas suas próprias candidaturas e documentos. |
| RN07 | O RH deve conseguir visualizar candidatos somente das vagas sob sua responsabilidade ou conforme permissão administrativa. |
| RN08 | Documentos enviados devem respeitar formatos e limites definidos nos requisitos não funcionais. |
