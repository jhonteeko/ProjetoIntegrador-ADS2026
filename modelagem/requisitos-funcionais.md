# Requisitos Funcionais

| Código | Requisito | Descrição |
| ----- | ----- | ----- |
| RF01 | Realizar login | Permitir que candidato, RH e administrador acessem o sistema com e-mail e senha, respeitando o perfil de acesso. |
| RF02 | Cadastrar usuário candidato | Permitir que candidatos criem conta informando dados básicos necessários ao acesso ao portal. |
| RF03 | Recuperar senha | Disponibilizar processo de recuperação de acesso por e-mail ou mecanismo equivalente. |
| RF04 | Cadastrar currículo | Permitir que o candidato registre dados pessoais, experiências, formação, competências e informações complementares. |
| RF05 | Editar currículo | Permitir que o candidato atualize suas informações sempre que necessário. |
| RF06 | Visualizar vagas | Exibir vagas abertas com informações de título, descrição, requisitos, local, modalidade e tipo de contratação. |
| RF07 | Candidatar-se a vaga | Permitir que o candidato envie sua candidatura para uma vaga aberta, vinculando seu currículo à oportunidade. |
| RF08 | Acompanhar processo seletivo | Permitir que o candidato visualize o status de cada candidatura, como inscrito, em análise, entrevista, aprovado ou reprovado. |
| RF09 | Enviar documentos | Permitir que candidatos aprovados enviem documentos de contratação em formatos aceitos pelo sistema. |
| RF10 | Cadastrar vagas | Permitir que o RH cadastre novas vagas com título, descrição, requisitos, local, modalidade, tipo de contratação e prazo. |
| RF11 | Editar ou encerrar vagas | Permitir que o RH altere informações de vagas existentes ou encerre vagas que não estejam mais disponíveis. |
| RF12 | Visualizar candidatos inscritos | Permitir que o RH consulte a lista de candidatos inscritos em cada vaga e acesse seus currículos. |
| RF13 | Atualizar status do candidato | Permitir que o RH registre a evolução do candidato nas etapas do processo seletivo. |
| RF14 | Solicitar documentos | Permitir que o RH solicite documentos ao candidato aprovado antes da admissão. |
| RF15 | Realizar triagem assistida por IA | Permitir que o sistema analise currículo e requisitos da vaga, gerando uma sugestão de aderência para apoio ao RH. |
| RF16 | Gerar relatórios básicos | Permitir que o RH visualize dados simples, como quantidade de inscritos por vaga e status das candidaturas. |
